# 🏨 Resort Odisej — Interactive Resort Website

A modern and visually engaging **resort/hotel landing page** built using **HTML, CSS, JavaScript, and GSAP**. The project focuses on creating a premium hospitality experience through smooth animations, immersive imagery, and scroll-based interactions.

> **Academic / Portfolio Project**
> Developed as part of my web development learning journey as a **3rd-year Computer Science student**.

## 📌 About The Project

**Resort Odisej** is a responsive and interactive hotel/resort website inspired by modern luxury hospitality websites.

The primary goal of this project was to practice:

* Modern website layout design
* Responsive web development
* JavaScript-based interactions
* GSAP animations
* Scroll-triggered animations
* Image-based visual storytelling
* Clean and structured frontend development

The website presents **Hotel Odisej, Mljet** with an immersive visual experience highlighting the resort, its surroundings, rooms, and booking-related actions.

## 🎬 Animation & Interaction

One of the main highlights of this project is the use of **GSAP and ScrollTrigger**.

The project includes:

* Page-load entrance animations
* Image scaling effects
* Navigation animations
* Scroll-based text color transitions
* Pinned image effects
* Animated headings
* Scroll-triggered image reveals
* Smooth content transitions

GSAP is used to create a more dynamic and engaging user experience instead of relying only on static CSS effects.

## 📂 Project Structure

```text
Resort-odisej/
│
├── index.html
├── style.css
├── script.js
├── Odisej_exterior_aeria.jpg
└── README.md
```

### File Description

**`index.html`**
Contains the main structure and content of the website, including navigation, resort sections, room information and external booking links.

**`style.css`**
Handles the visual presentation, layout, typography, spacing and responsive styling.

**`script.js`**
Contains the JavaScript animation logic using GSAP and ScrollTrigger.

**`Odisej_exterior_aeria.jpg`**
Main resort exterior image used in the hero section.
